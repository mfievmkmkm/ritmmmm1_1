# Ритм — личный планировщик

Личный PWA-планировщик задач и привычек с Supabase. Данные доступны только авторизованному владельцу. Подготовлен для GitHub Pages.

## Публикация

Откройте **Settings → Pages** → **Deploy from a branch** → `main` / `/(root)` → **Save**.

## Supabase

Проект: `ritm` (`vivxrtkzmkpvtbbkcfna`). База и RLS настроены. В Supabase Authentication → URL Configuration задайте Site URL `https://mfievmkmkm.github.io/ritmmmm1_1/` и добавьте этот же URL в Redirect URLs.

Используется только публичный ключ Supabase. Секретные ключи в репозиторий не добавляются.

## Использование

Зарегистрируйтесь через кнопку «Войти» и подтвердите почту. После входа задачи будут сохраняться в Supabase, а при отключении интернета — на устройстве до следующей синхронизации. Периодически экспортируйте резервную копию из настроек.
